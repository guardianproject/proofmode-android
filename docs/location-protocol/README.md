# Location Protocol — User Docs

Guides for enabling location attestations in Proofmode: signing where and when media was captured, optionally anchoring those claims on a blockchain, and backing up proof sets to IPFS via Filebase.

| If you want to… | Open |
|-----------------|------|

## Placeholders

Some steps need values from your event or deployment organizer. Replace these before following the tutorial:

| Placeholder | Where it is used |
|-------------|------------------|
| `<NETWORK_NAME>` | Wallet Settings → Network |
| `<ZERODEV_ID>` | Wallet Settings → ZeroDev project ID |
| `<IPFS_BEARER_TOKEN>` | Auto Sync → IPFS Bearer Token |
